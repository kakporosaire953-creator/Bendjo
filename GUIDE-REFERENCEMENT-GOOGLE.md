## 🚀 Comment Référencer votre Site sur Google Search Console

### **Étape 1 : Accéder à Google Search Console**

1. Allez sur : **https://search.google.com/search-console/**
2. Connectez-vous avec votre compte Gmail (utilisez un compte professionnel si possible)

### **Étape 2 : Ajouter votre Propriété**

1. Cliquez sur **"Ajouter une propriété"** (en haut à gauche)
2. Choisissez **"Préfixe d'URL"** (c'est plus simple)
3. Entrez votre URL : `https://bendjo-mu.vercel.app`
4. Cliquez sur **"CONTINUER"**

### **Étape 3 : Vérifier la Propriété**

Google vous propose plusieurs méthodes de vérification. Voici **la méthode la plus simple pour Vercel** :

#### **Option A : Balise Meta HTML (RECOMMANDÉ)**

1. Google vous donnera une balise meta qui ressemble à :
   ```html
   <meta name="google-site-verification" content="VOTRE_CODE_ICI" />
   ```

2. **Copiez cette balise**

3. Envoyez-moi le code pour que je l'ajoute dans le fichier `index.html` (dans la section `<head>`)

4. Je ferai le push, attendez que Vercel redéploie (2-3 minutes)

5. Retournez sur Google Search Console et cliquez sur **"VÉRIFIER"**

#### **Option B : Enregistrement DNS (Alternative)**

Si vous avez un nom de domaine personnalisé avec accès au DNS :

1. Google vous donnera un enregistrement TXT
2. Ajoutez-le dans les paramètres DNS de votre domaine
3. Attendez quelques minutes pour la propagation
4. Cliquez sur **"VÉRIFIER"**

### **Étape 4 : Soumettre votre Sitemap**

Une fois la propriété vérifiée :

1. Dans le menu de gauche, cliquez sur **"Sitemaps"**
2. Dans le champ "Ajouter un sitemap", entrez : `sitemap.xml`
3. Cliquez sur **"ENVOYER"**

✅ Google commencera à explorer votre site dans les 24-48 heures

### **Étape 5 : Demander une Indexation Rapide (Optionnel)**

Pour accélérer l'indexation de votre page d'accueil :

1. Dans le menu de gauche, cliquez sur **"Inspection de l'URL"**
2. Entrez : `https://bendjo-mu.vercel.app`
3. Attendez l'analyse (environ 1 minute)
4. Cliquez sur **"DEMANDER UNE INDEXATION"**
