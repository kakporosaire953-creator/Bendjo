# 🔐 Accès Panel Administrateur BenDjo

## Route d'accès sécurisée

Le panel d'administration n'est **pas accessible via un bouton visible** sur le site pour des raisons de sécurité.

---

## 💻 Accès sur Desktop (Ordinateur)

### Méthode : Code clavier

1. Ouvrez n'importe quelle page du site BenDjo
2. Tapez le code secret suivant au clavier : **`admin2026`**
3. Le panel administrateur s'ouvrira automatiquement

**Code secret : `admin2026`**

**Remarque :**
- Tapez le code en minuscules
- Pas besoin d'appuyer sur Entrée
- Le code fonctionne sur n'importe quelle page

---

## 📱 Accès sur Mobile (Smartphone/Tablette)

### Méthode : Triple-Tap

Sur mobile, impossible de taper au clavier, donc utilisez cette méthode :

1. Ouvrez n'importe quelle page du site BenDjo
2. **Tapez 3 fois rapidement** dans le **coin en bas à droite** de l'écran
3. Le panel administrateur s'ouvrira automatiquement

**Zone de triple-tap :**
```
┌─────────────────────┐
│                     │
│                     │
│                     │
│                     │
│                 ┌───┤ ← Tapez ici
│                 │XXX│    3 fois
│                 │XXX│    rapidement
└─────────────────┴───┘
```

**Remarques importantes :**
- Les 3 taps doivent être faits en moins d'1 seconde
- Tapez dans les 20% en bas à droite de l'écran
- Si ça ne marche pas du premier coup, réessayez

---

## ⚙️ Fonctionnalités du panel admin

Une fois connecté, vous pouvez :

- ✅ Ajouter de nouveaux produits
- ✅ Modifier les produits existants
- ✅ Supprimer des produits
- ✅ Gérer les prix et descriptions
- ✅ Upload d'images/vidéos pour les produits

---

## 🔒 Sécurité

**Gardez ces méthodes d'accès confidentielles** et ne les partagez qu'avec les personnes autorisées à gérer le catalogue de produits.

### Récapitulatif des accès :

| Appareil | Méthode | Action |
|----------|---------|--------|
| 💻 Desktop | Clavier | Taper `admin2026` |
| 📱 Mobile | Tactile | Triple-tap en bas à droite |
